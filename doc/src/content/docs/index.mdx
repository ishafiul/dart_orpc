## Install

```bash
dart pub add dart_orpc
```

Add generation tools for application contracts:

```sh
dart pub add --dev build_runner dart_orpc_generator
```

## Build your application step by step

New to the framework? Read the [Build an App handbook](/dart-orpc/handbook). Its ordered chapters explain server setup, every major configuration option, controllers, providers, module imports/exports, global modules, data validation, environment, middleware, guards, rate limits, CORS, OpenAPI, typed clients, and monorepo choices. The final chapter combines them into one server.

## Learn the framework

Start with [philosophy and core concepts](/dart-orpc/core-concepts), follow the [working quick start](/dart-orpc/quick-start), then [build a feature-based app](/dart-orpc/guides/create-an-app). Keep the [API reference](/dart-orpc/reference) and [good practices](/dart-orpc/guides/practices-and-tips) nearby as your app grows.
