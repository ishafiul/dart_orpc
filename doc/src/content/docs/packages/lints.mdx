---
title: Lint packages
description: strict_dart_lints for any Dart code and dart_orpc_lints for dart_orpc apps, both analyzer plugins with error-level rules.
---

| Package | Layer | Contents |
| --- | --- | --- |
| `strict_dart_lints` | Base, any Dart code | `strict.yaml` and `library.yaml` presets; rules for comments, ignore reasons, `!`, `as`, `Future.delayed`, `late`, hard-coded strings, mirrors, mutable globals, broad catches |
| `dart_orpc_lints` | dart_orpc apps | `app.yaml` preset; rules for framework errors, manual routes, controller logic, module boundaries, manual provider construction |

Add `dart_orpc_lints` as a dev dependency; it depends on `strict_dart_lints`. Enable both plugins in `analysis_options.yaml`, so each rule keeps its `plugin/rule` name for ignore comments.

Every rule reports an error, skips generated files, and explains the fix that removes the cause. Most production-only rules exempt `test/`.

See [Strict Linting](/dart-orpc/guides/strict-linting) for setup, the full rule list, and suppressing a rule with a reason.
